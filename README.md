# CodeAlpha Stock Trading Platform

## About the Project
A console-based Java application that simulates a basic stock trading environment. Users can view available stocks, buy and sell shares, and track their portfolio using virtual money.

## Features
- View available stocks and their prices
- Buy stocks
- Sell owned stocks
- View portfolio and total stock value
- Check available balance
- Prevent purchases when the balance is insufficient
- Prevent selling more shares than owned

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- Classes and Objects
- Arrays
- Scanner
- Conditional Statements and Loops

## How to Run
Compile the program:

```bash
javac Main.java
```

Run the program:

```bash
java Main
```

## Disclaimer
This project is for educational purposes only. It uses sample stock prices and virtual money, not real-time market data.
